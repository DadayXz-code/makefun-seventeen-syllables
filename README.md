One haiku about debugging, in the 5-7-5 syllable shape — seventeen syllables in total. A cursor blinking at 3 a.m., a breakpoint that never fires, a log line that swears nothing is wrong — and after all of it, the bug was a typo.

```
Cursor blinks at three
the breakpoint sleeps, the log lies
it was a typo
```

## Run it

```sh
python3 main.py
```

The program is deterministic: every run writes the exact same bytes to `/output/entry.txt` and exits 0. It needs no arguments, no network, and no secrets.
